# 조사 완료 후 리포트 요구사항

사용자 추가 요청: 기념일 조사 후 종류를 요약한 리포트를 작성한다.

## 최종 리포트 구성
- 연구 완료 records.json과 proposed-anniversaries.json을 실제로 읽고 프로그램으로 집계한다. 진행 중 수치는 최종 결과로 쓰지 않는다.
- 전체 조사 후보 수, evidenced/review/blocked/rejected 상태별 건수 및 서비스 반영 여부를 명시한다.
- 종류별 분류: 현재 categories.json의 실제 카테고리로 집계하고, 필요하면 보건·인권·문화·과학·동물·지역 전통 같은 편집 소분류를 별도로 명시한다.
- 각 후보: 한국어 이름, 원명, 날짜/반복 규칙, 적용 국가·범위, 기념하는 대상, 핵심 출처 URL, 기존 데이터와의 차이.
- 기존 데이터 및 이전 연구 배치와 중복된 항목, 근거 부족/날짜 불확실로 보류한 항목을 구분한다.
- AnniCal 데이터 다양성/선택지가 부족한 날짜 보완 관점에서 추천 우선순위를 제시하되 승인과 구분한다.
- 검증 결과 및 남은 검수 과제를 기재한다. 검색 요약이나 Claude 완료 메시지만으로 사실 검증 완료라고 쓰지 않는다.
- Markdown 보고서 report.md를 이 배치에 저장하고 Discord에는 표 대신 종류별 bullet과 핵심 결과를 제공한다.
- 서비스 데이터 반영·배포는 별도 승인 전 수행하지 않는다.
