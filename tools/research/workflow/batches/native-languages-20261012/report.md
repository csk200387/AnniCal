# AnniCal 현지어 기념일 조사 보고서

## 조사 범위 및 상태

Claude Code에서 8개 국가·지역의 현지어로 25회 검색했다. 영어 목록을 번역한 작업이 아니라 검색 언어·검색어·결과 URL을 search-log.json에 기록한 조사다.

Claude Code는 이용 한도(HTTP 429)로 최종 검증·보고서 작성 전에 중단됐다. 이 보고서는 이미 저장된 조사 기록을 부모 작업자가 집계하고 점검한 결과다. 추가 검색을 다른 도구나 유료 API로 대체하지 않았다. 자동 재개는 설정하지 않았다.

총 24개 기록: 원문 확인 신규 후보 14개, 단일 출처 미검증 후보 5개, 날짜 규칙 미지원 보류 3개, 원문 미확인 검색결과 후보 1개, 기존 데이터 중복 1개. 단일 출처 후보를 포함한 신규 검토 후보는 19개이며 승인된 항목은 없다.

## 검증 및 제한

- 고유 후보 키 24개 확인. 현지어 검색 로그 언어·국가 매칭 정상.
- 원본 해시 45개 일치. 보호 대상 2354개 파일 해시 비교에서 변경 없음.
- 주장 인용 76개 중 75개가 기록에 연결된 저장 본문과 문자 그대로 일치.
- 폴란드 땡땡이의 날의 secondary_note 인용은 해당 후보 evidence 목록에 ox-pl-witaj-wiosno 참조가 없어 검증되지 않았다. 주된 자료와 별개인 보조 주장이다. 원문 연결을 복구하고 독립 검수하기 전 확정 근거로 쓰지 않는다.
- 원문 인용 일치 검사는 번역 정확성이나 전체 본문 사실성을 보증하지 않는다. 아래 설명은 조사 초안이다.
- 날짜 resolver 검사와 독립 의미적 중복 검수는 완료하지 않았다. 이동일 보류는 기념일이 없다는 뜻이 아니라 현재 앱 날짜 자료가 부족하다는 뜻이다.
- 서비스 반영·커밋·배포 미실행.

### Weiberfastnacht — 여자들의 카니발 날(바이버파스트나흐트) — 넥타이 자르는 날

- 날짜: 고정 날짜 미정·규칙 보류 / 재의 수요일 전 목요일 = 부활절 일요일 52일 전(원문: 2026년 2월 12일). 서비스 데이터에 부활절 기준 anchor 가 없어 현재 dateType 으로 표현 불가 → 규칙 미지원. 특정 연도 날짜를 고정일로 만들지 않음
- 범위·구분: 라인란트(쾰른·본·뒤셀도르프·아헨) 중심 카니발 지역. 공휴일 아님 / 지역 전통
- 조사 상태: 보류 — 날짜 규칙 미지원(부활절·음력 표 없음)
- 의미(조사 초안): 카니발 거리 축제가 시작되는 재의 수요일 전 목요일, 라인란트에서 하루 동안 여성이 도시를 '접수'하는 날이다. 분장한 여성들이 시청을 점거하고, 남성 권력의 상징인 넥타이를 가위로 잘라 버린다. 본 보이얼 지역 세탁부 여성들이 1824년 '보이얼 여성위원회'를 만든 것이 시작으로 전해진다.
- 주의·미확인: 넥타이 풍습의 시작 연도는 같은 기사 안에서도 상충 — '1824년 보이얼 여성 모임'만 기원으로 쓰고 넥타이는 '20세기 중반 확산'으로만 쓸 것. 부활절 연동이라 부활절 anchor 또는 표가 생기기 전엔 등록 불가.
